AI model prices and context limits

Compare listed model prices and context limits.

Our analysis · R + SQL · One point in time

We use 304 model listings from 12 developers. OpenRouter lists the base price to route text to each model. We show dollars per million tokens. A token is a unit of text a model reads or writes. These prices do not show sales, usage, or chat subscription fees. Source and price fields.

How context size and price are linked

To study prices, we fit a regression. It links context size to output price. It also accounts for who makes the model and whether it reads images. The equation is:

\[\log(p_j)=\alpha+\beta\log(c_j)+\gamma_{developer(j)}+\delta\,image_j+\epsilon_j.\]

The fit uses 283 model versions. The context coefficient is 0.171, and R² is 0.382. R² measures the share of variation in log prices that the fit explains in this sample. At twice the context size, the fitted output price differs by about 12.6%. This holds the developer and image support fixed.

This fit does not show cause and effect. It does not tell us how buyers would react to a price change. More context does not prove better quality. We lack matched scores over time, demand, and the cost of running each model. We also lack price changes driven by outside events. Model families and firms may share errors. We do not treat each listing as an independent sample for tests of significance.
